# GENGIS landing

Landing del observatorio GENGIS (Club Kongzhi UNMSM). Sitio estático, sin build.
Repositorio independiente: no comparte código con Biblioteca Nalanda ni con el repo de GENGIS.

- Publicar: Settings > Pages > Deploy from branch > main / (root).
- Enlaces a Nalanda: https://renzo34990.github.io/gengis-biblioteca/ (editar en index.html si cambia la URL).
- Fuentes autoalojadas en assets/fonts.
